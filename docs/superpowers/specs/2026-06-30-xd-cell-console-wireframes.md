# XD Cell Console 低保真布局草图

本文是 [XD Cell Console 产品与架构讨论稿](2026-06-30-xd-cell-console-product-design.md) 的配套草图，用于辅助讨论顶部栏、workspace 侧栏、站点详情、团队详情和 admin 菜单。

## 首页 / 站点目录

所有 `workers.xd.team/*` console 页面、静态资源和 `/api/console/*` 都先经过公司网络 / VPN / 办公网 IP allowlist。下方未登录状态只表示“已通过 IP allowlist 但没有用户 session”。

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ XD Cell   Sites   工作台                                      主题 语言 通知 用户 │
├──────────────────────────────────────────────────────────────────────────────┤
│ Sites                                                                        │
│ 未登录: [internal]                                                           │
│ 登录后: [全部可见] [个人] [团队] [internal] [org] [acl] [owner] [状态]          │
│                                                                              │
│ ┌──────────────────────┐  ┌──────────────────────┐  ┌──────────────────────┐ │
│ │ site-slug            │  │ another-site         │  │ team-service         │ │
│ │ hostname             │  │ hostname             │  │ hostname             │ │
│ │ [个人] [internal]    │  │ [团队][部门团队][org] │  │ [团队][acl][failed]  │ │
│ │ owner display name   │  │ owner display name   │  │ owner display name   │ │
│ │ updated 2h ago       │  │ updated yesterday    │  │ failed 12m ago       │ │
│ └──────────────────────┘  └──────────────────────┘  └──────────────────────┘ │
│ ┌──────────────────────┐  ┌──────────────────────┐                           │
│ │ slug-only fallback   │  │ hostname-only fallback│                           │
│ │ hostname             │  │ hostname             │                           │
│ │ [团队] [owner]       │  │ [个人] [active]       │                           │
│ └──────────────────────┘  └──────────────────────┘                           │
└──────────────────────────────────────────────────────────────────────────────┘
```

站点面板以 slug / hostname 为主，不要求站点配置额外展示字段。未登录但已通过 IP allowlist 时，只出现可直接判断为可见的 `internal` 站点和 internal 筛选；登录后再展示个人、团队、ACL、org、internal 等可访问站点和完整筛选。

## 站点子页面

用户从个人站点或团队站点列表进入某个站点后，左侧切换为当前站点上下文。部署记录、访问控制和运行配置都属于站点详情，不放在 Workspace 全局侧边栏。

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ XD Cell   Sites   工作台                                      主题 语言 通知 用户 │
├───────────────────┬──────────────────────────────────────────────────────────┤
│ ← 所有站点         │ 站点 / site-slug                              [团队] [active] │
│ site-slug          │                                                          │
│ hostname           │ 站点概览 / 当前功能内容                                   │
│ [visibility][状态] │                                                          │
│ - 概览             │                                                          │
│ - 部署记录          │                                                          │
│ - 访问控制          │                                                          │
│ - 运行配置          │                                                          │
│ - 设置             │                                                          │
└───────────────────┴──────────────────────────────────────────────────────────┘
```

## 团队子页面

团队详情页不是普通 Workspace 菜单加内容 tabs。用户从 `协作 / 团队` 进入某个团队后，左侧切换为当前团队上下文；团队名下直接放一级导航，不再增加分组标题。顶部全局栏仍保持 XD Cell 全局导航。

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ XD Cell   Sites   工作台                                      主题 语言 通知 用户 │
├───────────────────┬──────────────────────────────────────────────────────────┤
│ ← 所有团队         │ 团队 / Web 平台支撑 / 成员                    [部门团队] [admin] │
│ Web 平台支撑       │ 团队成员                                                 │
│ [部门团队] [admin] │ user / role / source / updatedAt                         │
│ - 成员             │                                                          │
│ - Access Keys     │                                                          │
│ - 设置             │                                                          │
└───────────────────┴──────────────────────────────────────────────────────────┘
```
